# Bestiary

## Objetivo

Registrar conhecimento adquirido sobre inimigos.

## Problema

Jogadores esquecem:

- hp
- ac
- ataques
- resistências
- padrões

## Solução

Criar bestiário pessoal.

## Features

### Monster Card

- nome
- imagem
- primeira aparição
- última aparição

### Estatísticas

- hp estimado
- ac estimada
- ataque estimado

### Conhecimento

- resistências
- imunidades
- fraquezas

### Inteligência

- comportamento
- padrões

## UX

Visual estilo Pokédex.

## Critérios de aceite

- criar inimigo
- editar inimigo
- pesquisar inimigo
- associar sessões
- calcular confiança
